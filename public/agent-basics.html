Agents: an early reading

Unit 2, Introduction to Agentic Systems, is still being planned. This early reading is for people who already use an agent tool or are curious about one. It is optional and does not affect Unit 1 or its completion.

A helper that works on your computer

Andrej Karpathy describes an agent on your computer as “a little spirit/ghost that "lives" on your computer”. It is a useful image: imagine showing a new helper around your workspace. Here is the project folder; here are my notes; here is where the finished work belongs.

The ghost is a metaphor. An agent works through the tools and access its app provides. Some tools let it inspect a screen and click through windows; others let it list folders, search or read files, and save results using paths. The AI model may run remotely even when its tools work on your computer. Learning a little of this geography makes its actions easier to follow—and makes your directions more useful.

You might recognise a note by its icon or remember opening it yesterday. An agent using file tools can list the contents of a folder, search for a filename or phrase, then read a file at its path. With computer-use tools, it may navigate Finder or File Explorer much as you do, including entering a folder path to go straight there. These are different ways into the same file system: the arrangement of files and folders covered in Files, folders and locations.

Point it to the right place

Before you give an agent a path, check which computer, workspace and folder it can actually access. A path on your Mac is not automatically available on a remote server.

Finlay’s tip · Copy the path when giving directions

I use Copy as Pathname a lot when talking to my agents. It lets me point to the exact file or folder I mean. Try writing: “Read the note at [paste the full path here] and summarise it in two sentences.” Keep this as a practice instruction until you know whether your AI has access to that location.

If an agent says it saved a file, ask “Which computer or workspace, and what full path?” Then open the file and check the contents. A file in the agent’s workspace may still need downloading to yours.

Where does your helper keep its notes?

Alongside the files you ask them to work on, some agent apps keep guidance and records they can use next time. Think of these as the helper’s working notes and controls:

  • Instructions: guidance you provide about working with you or on a project. Some tools read specially named files, such as CLAUDE.md, from particular folders.
  • Memory: saved details or summaries the app can bring into a later conversation, such as a preference you have explained or something learned about a project. Depending on the app, these may live in local files or in the service’s own storage.
  • Settings: controls for how the app operates, including which tools it can use and what access they have. These may appear in a settings screen or be stored in configuration files.

There is no single folder that every AI uses for these things. Some files belong to one project; others sit in the app’s own folders, which may be hidden from everyday view. For a concrete example, Claude Code documents its instruction and memory files separately from its settings files. You do not need to install it or edit those files to follow this reading.

A useful question for an agent is: “What instructions and saved memories are you using for this task? Show me where I can review them, and tell me what you cannot inspect.” Check its answer against the files or app controls you can open. A saved note only helps if the tool actually loads it. You can make your own reusable guidance in the Save and reuse context activity; knowing where it lives helps you find, review and update it.

What are CLAUDE.md and AGENTS.md?

These are names some agent tools use for plain-text instruction files. The .md ending means Markdown: text with simple headings and lists. Claude Code uses CLAUDE.md; Codex and other supporting tools use AGENTS.md. Current Claude Code versions can also support AGENTS.md under particular conditions.

You can create the content of these files from your personal and project briefs. The tool determines where they belong and which it reads. They guide behaviour; they do not guarantee compliance or permanently train a model. You do not need to install a coding tool: pasting the selected guidance into a chat works too.

Optional: I already use a supporting agent

Check its current instructions before saving a file: Codex instruction guide (opens a new tab) or Claude Code instruction guide (opens a new tab). Use a non-sensitive practice project, inspect which instruction sources loaded, and test one expected behaviour. If the feature is unavailable, use the copy-and-paste route.
