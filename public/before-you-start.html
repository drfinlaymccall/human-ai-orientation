Files, folders and locations

What does your computer look like to an AI working on your behalf? This short tour helps you get your bearings in the places an agent may work: folders, files and the paths between them. Learn to point it towards the right material, find what it makes, and understand where the guidance it uses might live.

Andrej Karpathy describes an agent on your computer as “a little spirit/ghost that "lives" on your computer”. It is a useful image for this tour: imagine showing a new helper around your workspace. Here is the project folder; here are my notes; here is where the finished work belongs.

The ghost is a metaphor. An agent works through the tools and access its app provides. Some tools let it inspect a screen and click through windows; others let it list folders, search or read files, and save results using paths. The AI model may run remotely even when its tools work on your computer. Learning a little of this geography makes its actions easier to follow—and makes your directions more useful.

About 10–15 minutes for computer basics · Optional familiar-skills practice. No AI account is needed for the computer basics. Use a Mac or Windows computer for the file hunt. You will work with a new practice file, not reorganise your existing documents.

First, see what you already know

Could you do these three things now?

  • Find a downloaded file and put a copy in a folder you chose.
  • Show where that file lives and open it again after closing the window.
  • Explain why telling a web chatbot a file’s location does not give it the file.

If all three are familiar, try the quick self-check and jump to getting to know your AI. If something is unfamiliar, follow the hunt below. Your answers are for you; this page does not save or grade them.

I am on a phone, tablet or a computer where I cannot save files

Read the examples and try the self-check. Keep your notes in an app you already use and use the copy-and-paste route in the AI lesson. You can return to the desktop hunt later. Recognising an example is useful, but it is different from practising on your own device.

A small map of your files

A file is a saved item, such as a note or photograph. A folder holds files and other folders. A path describes the route through those folders to an item.

Documents
└── AI Orientation
    └── Practice
        └── my-practice-note.md

The file is my-practice-note.md. Its containing folder is Practice. The ending .md means Markdown: plain text that can use simple marks for headings and lists.

Example full paths look like these. Sam is a fictional username; your path will be different.

  • Mac: /Users/Sam/Documents/AI Orientation/Practice/my-practice-note.md
  • Windows: C:\Users\Sam\Documents\AI Orientation\Practice\my-practice-note.md

Some computers keep Documents inside iCloud Drive or OneDrive, so those names may appear in the path. A folder visible on your computer may also be synchronised to a cloud service. “Recent” and “Quick access” help you find items; they are not necessarily where the file is stored.

You might recognise a note by its icon or remember opening it yesterday. An agent using file tools can list the contents of a folder, search for a filename or phrase, then read a file at its path. With computer-use tools, it may navigate Finder or File Explorer much as you do, including entering a folder path to go straight there. These are different ways into the same file system: the arrangement of files and folders you are about to explore.

The find-it-again scavenger hunt

Make a small workspace you could show an agent around. You will find a note, copy its address and return to it—useful moves whether you are doing the work yourself or directing a helper. Choose your computer’s instructions. Menu wording can differ by version.

Mac: use Finder
  1. Open Finder, the smiling face in the Dock. Locate Documents and Downloads in its sidebar, or use Finder’s Go menu.
  2. In Documents, choose File → New Folder. Name it AI Orientation. Open it and create another folder named Practice.
  3. Choose View → Show Path Bar. This shows the folders leading to your current location near the bottom of the window.
  4. To copy an address you can give an agent, right-click the Practice folder (or Control-click it), then hold Option while the menu is open. Choose Copy “Practice” as Pathname and paste it into your notes. Option reveals the pathname command; Control-click is a way to open the menu.
Windows: use File Explorer
  1. Press the Windows key + E to open File Explorer. Locate Documents and Downloads in the navigation pane or Home / Quick access.
  2. Open Documents, then choose New → Folder (or right-click an empty area and choose New → Folder). Name it AI Orientation. Open it and create another folder named Practice.
  3. Look at the address bar near the top: it shows the folders leading to your location. In Windows 11, View → Show → File name extensions lets you see endings such as .md.

Collect your practice note

  1. Download the small practice note. It contains only fictional practice text.
  2. Find it using your browser’s download list and its Show in Finder or Show in folder option. Downloads is a common location, but your browser may use a different folder or ask you where to save.
  3. Select the file and copy it: Command+C on Mac or Ctrl+C on Windows. Open your new Practice folder and paste with Command+V or Ctrl+V. This keeps the original download.
  4. Rename the copy my-practice-note, keeping its .md ending. On Mac, select it and press Return; on Windows, right-click and choose Rename. If the ending is hidden, change only the displayed name.
  5. Right-click the copied file and use Open With to choose TextEdit on Mac, Notepad on Windows, or Obsidian if it is already set up. Find the words “Found it again!” inside. There is nothing to install just to read this note.
  6. Close the file and folder windows. Open Finder or File Explorer again, navigate back to Practice and reopen the note. Can you find it without the browser’s download list?
If the download opened as text instead

Return to this page, right-click the download link and choose Save Link As / Download Linked File. Save it in the Practice folder, then find and open it there. If saving is unavailable, use the example folder map and return to the practical task later.

Find its address

On Mac, right-click the file, hold Option, then choose Copy “my-practice-note.md” as Pathname. On Windows 11, right-click the file and choose Copy as path; on older menus, hold Shift while right-clicking. Paste the path into your own notes and identify the containing folder. You do not need to send the path to us.

Finlay’s tip · Copy the path when giving directions

I use Copy as Pathname a lot when talking to my agents. It lets me point to the exact file or folder I mean. Try writing: “Read the note at [paste the full path here] and summarise it in two sentences.” Keep this as a practice instruction until you know whether your AI has access to that location.

Finlay’s tip · Give your notes a home

I recommend Obsidian for keeping your briefs, useful responses and reflections together. Its “vault” is an ordinary folder of Markdown notes, so the folder skills you are practising here carry straight across.

Set up Obsidian with the step-by-step guide. You can also keep using your existing notes app.

Pointing your AI at something

A path tells a tool where to look. It does not grant access. A web chatbot usually cannot open a file on your computer just because you paste its path.

  • For a few sentences: open your note and paste only the relevant text into the chat.
  • For an attachment: if your tool supports uploads, use its attachment button and select the intended file. Check the filename before sending.
  • For an agent with file access: check which computer, workspace and folder it can actually access, then give it the relevant path. A path on your Mac is not automatically available on a remote server.

Where did the AI put the result?

If it only wrote a reply, the result is still in the chat: copy it into your note. If it offers a file, download it and locate it using your browser’s download list. If an agent says it saved a file, ask “Which computer or workspace, and what full path?” Then open the file and check the contents. A file in the agent’s workspace may still need downloading to yours.

Finlay’s tip · Find it before you finish

Before closing a session, open the result from the place you plan to keep it. A useful filename and a folder you can find again are part of finishing the task.

Where does your helper keep its notes?

Once paths make sense, another part of working with agents becomes easier to understand. Alongside the files you ask them to work on, some agent apps keep guidance and records they can use next time. Think of these as the helper’s working notes and controls:

  • Instructions: guidance you provide about working with you or on a project. Some tools read specially named files, such as CLAUDE.md, from particular folders.
  • Memory: saved details or summaries the app can bring into a later conversation, such as a preference you have explained or something learned about a project. Depending on the app, these may live in local files or in the service’s own storage.
  • Settings: controls for how the app operates, including which tools it can use and what access they have. These may appear in a settings screen or be stored in configuration files.

There is no single folder that every AI uses for these things. Some files belong to one project; others sit in the app’s own folders, which may be hidden from everyday view. For a concrete example, Claude Code documents its instruction and memory files separately from its settings files. You do not need to install it or edit those files for this activity.

A useful question for an agent is: “What instructions and saved memories are you using for this task? Show me where I can review them, and tell me what you cannot inspect.” Check its answer against the files or app controls you can open. A saved note only helps if the tool actually loads it. Later in the course, you will make your own reusable guidance in the personal context portfolio; knowing where it lives helps you find, review and update it.

Quick self-check

Say or write your answer before opening each explanation.

1. In AI Orientation/Practice/my-practice-note.md, what is the file, and which folder contains it?

Check your answer: file and folder

The file is my-practice-note.md; it is inside Practice, which is inside AI Orientation. If you picked AI Orientation as the file, revisit the folder map.

2. You paste a local file path into a web chat. Has the AI now read your note?

Check your answer: access

No. The path alone supplies neither the contents nor permission to read them. Paste selected text, deliberately attach the file, or verify that a supporting agent has access to that location.

3. The AI says “I saved your brief,” but you cannot find it in Documents. What would you check?

Check your answer: finding a result

Find out whether it produced chat text, a downloadable file or a file in another workspace. Check the browser’s download location or ask for the actual workspace and path. Verify by opening the result; the claim alone is not enough.

Your finish line: find and reopen your practice note, copy its path, and explain how you would point an agent towards it. Name one deliberate way to share its contents. You now have the beginnings of a shared map: where the source is, where the result should go, and where to look for guidance the agent might use next time. Keep a short note of anything you want help with. If you used the read-through route, record that and practise finding a real file when you can.
