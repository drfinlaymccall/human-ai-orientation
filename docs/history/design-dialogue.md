## Decisions that changed during development

- Audience framing changed from presumed low confidence to non-specialists with individually discovered needs.
- A broad ten-session idea became a three-activity release with optional preparation and staged expansion.
- Generic instructional-design framing was revised so Finlay's curriculum-design research leads.
- A static context template became an interactive builder, then a connected practice workspace, then a portable portfolio pathway.
- Export moved from the later wishlist into current delivery because it directly supports the North Star.
- GitHub moved from an intended publication destination to the public source and issue tracker.

## What is deliberately still unknown

Whether learners independently find the activities useful; how long the full journey takes; which optional modules merit expansion; physical-device and assistive-technology experience; sustainable support load. The pilot protocol asks for these observations. A site working in browser tests does not answer them.
