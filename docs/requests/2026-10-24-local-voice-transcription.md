# Feature request: local voice transcription

Requested by Finlay on 24 October 2026. Tracking: [#28](https://github.com/drfinlaymccall/human-ai-orientation/issues/28), under [voice parent #21](https://github.com/drfinlaymccall/human-ai-orientation/issues/21); canonical plan WB15. Status: queued for the voice channel; no local-model integration is implemented by this request.

Add an optional reference in the voice-notes/dictation guidance and the voice-feedback interface for learners using a sufficiently capable Mac or PC. Explain how a learner can install a local speech model and transcribe on their own computer as an alternative voice-input route. Finlay's preferred candidate is **Fluid Voice using a Parakeet model with on-device transcription**. This records his preference, rather than a verified claim that it is the best option or available on every platform.

Before publishing the recommendation:

- Verify the exact app, official download link, supported operating systems, hardware/memory requirements, model variant, licence and cost. Do not imply that Fluid Voice itself supports Windows without verification; offer a checked alternative if needed.
- Check which processing stays on-device and what requires an initial download or network connection. Use clear wording about transcription versus sending a voice recording to Finlay.
- Provide a short install → speak → review/correct → paste or explicitly send example. Cross-reference it from both voice notes and feedback, preserving the existing recording, typing and audio-upload routes.
- Test the instructions on representative supported hardware, or label any remaining device checks. Installation remains optional and is not required for course completion.

Documentation impact: update learner voice/dictation guidance, the feedback panel's optional help, relevant tool-source research, and CONTROL.md when this is scoped or delivered. No transcription service, API dependency or automatic feedback submission is authorised by recording the request.
