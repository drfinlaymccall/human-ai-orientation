# My starting point for working with AI

Draft learner-facing template, 13 October 2026. Intended to grow across the three orientation activities. Test and revise its wording with learners before publication.

Copy this into a document or notes app you can return to. Short answers are enough. You can use an invented example, leave out personal details, and change your mind. Share with an AI only the parts relevant to the task you want help with.

Some agent tools use instruction files named `CLAUDE.md` or `AGENTS.md`. You can create their content from these notes. The tool determines which file it reads and where it belongs; saving a file by itself does not share it with every AI. Pasting your selected guidance into a chat is also a useful way to start. See the [guided instruction activity](context-to-instructions.md).

## Start the next conversation

Choose relevant details from your notes and adapt this starter:

> I would like help with [goal], because [reason]. Here is the context that matters: [selected details]. I would like to begin with [small first step]. A useful result would [sign of success]. Before we start, ask me about any important information that is missing. Help me identify anything I need to understand and anything you need me to explain or provide. Treat this as a starting point we can revise.

Check the AI's interpretation before continuing. Supply missing context deliberately; having saved these notes does not automatically make them available to the AI.

You can use this starting point on your own. It can also support a later human–agent curriculum-design programme, where you develop the goal into specialist content and ways to evaluate your agent. You do not need access to another course to make use of what you have learned here.
