# Free consumer assistants: source review for WB18 / issue #12

Research date: **24 October 2026, Australia/Sydney**. Draft for integrator review; no consumer evaluation was run. Official pages were searched and fetched with the free TinyFish Search/Fetch tools. No paid Agent, browser session, account, subscription or inference API was used. Provider pages change; these findings describe the fetched documentation, not a guaranteed feature in a particular conversation.

## API and consumer boundaries

Google's [URL context documentation](https://ai.google.dev/gemini-api/docs/url-context) is explicitly for the Gemini **API**. Its supported MIME types can motivate a compatibility hypothesis, but do not document what gemini.google.com fetched. The existing text/plain correction and scoped edge rule remain historical operator evidence; the cause of Finlay's exact Gemini error remains unconfirmed.

Grok's Website / Apps FAQ is located under docs.x.ai but explicitly states that those sections concern consumer products. Its API-credit/team-management sections are excluded from this mapping. Likewise, a VPS Claude CLI source review, API tool response, local HTTP request or TinyFish extraction cannot count as a consumer assistant trial. The product surface and actual interaction determine the evidence class.

## Observations preserved, without ranking

The existing provider ledger records Finlay's anonymous/incognito ChatGPT success, signed-in Claude and Grok successes, and repeated Gemini retrieval failures including incognito and after compatibility changes. The Gemini response disclosed failed access and requested pasted text. These are **owner-reported sessions**, not fresh runs by this researcher. Exact models, signed-in plans, complete transcripts, tested region and controlled repeats were not recorded. Meta AI has no reported trial. The reports support keeping a paste route; they do not establish a provider-wide order of quality or a free-account success for the signed-in products.

## Source and retrieval checks completed here

TinyFish fetched the historical [2026-10-13.3 context](https://orientation.finlaymccall.com/ai/releases/2026-10-13.3/context.md), [current context](https://orientation.finlaymccall.com/ai/context.md) and [public HTML guide](https://orientation.finlaymccall.com/ai/). The current context and guide showed **2026-10-23.2**. The local pinned/current source copies matched the corresponding TinyFish extraction after whitespace normalization. This confirms an extracted-text match, not remote byte equality or HTTP response headers.

A plain Python urllib GET attempted each course URL but failed local DNS resolution. That tool limitation is recorded separately; no network escalation was needed because TinyFish retrieved the material. No paid fallback or authenticated connection was used. One guessed Claude Free-plan help URL returned 404; the final source table uses the fetched official free-access statement instead.

The controlled matrix remains **not tested in every consumer cell**. A signed-in free condition needs an owner-operated eligible account; do not mark it as a failed retrieval because this researcher did not sign in. Public availability, consumer entry, source retrieval, paste use, facilitation and human learning remain separate measurements.
