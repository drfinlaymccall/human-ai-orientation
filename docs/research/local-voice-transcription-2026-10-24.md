## Checked Windows candidate: Handy

[Handy](https://handy.computer/), by CJ Pais, is a separate free application with [MIT-licensed software](https://github.com/cjpais/Handy/blob/v0.9.8/LICENSE). Its [official repository](https://github.com/cjpais/Handy) documents local speech transcription on Windows, macOS and Linux. The [official release API](https://api.github.com/repos/cjpais/Handy/releases/latest) returned stable [v0.9.8](https://github.com/cjpais/Handy/releases/tag/v0.9.8), published 3 October 2026, with Windows **x64 and ARM64** `.exe`/`.msi` installers. This confirms distributed architectures; it does not establish every Windows version or CPU will work.

The [official model guide](https://handy.computer/docs/models.html) lists **Parakeet V3**, about **478 MB**, 25 languages, running on CPU. The [v0.9.8 model source](https://github.com/cjpais/Handy/blob/v0.9.8/src-tauri/src/managers/model.rs) identifies its INT8 TDT 0.6B v3 variant; this is a different packaged conversion from FluidVoice's Core ML files. Use the in-app model picker and do not install model files manually for the beginner route. A required Windows version, CPU instruction set and minimum/peak RAM were not established in the official pages inspected; check the actual learner computer before recommending it.

The [FAQ](https://handy.computer/docs/faq.html) attributes ordinary network requests to model downloads and update checks, with optional cloud post-processing sending text externally. The [advanced settings guide](https://handy.computer/docs/advanced.html) documents **Auto Submit: Off**, optional post-processing, clipboard handling and local history/recording retention. Keep Auto Submit and post-processing off; check history settings. Model licences remain separate from the app's MIT licence. No cloud API is recommended by this course option.
