Check your own screen: free does not mean unlimited. Features can differ by country, age, account, app version and device. School or work accounts may restrict them. Sources and practical limits for each tool
  • ChatGPT: Free plan, voice and dictation distinction, supported uploads. Voice and uploads have separate allowances.
  • Claude: plans, mobile dictation, voice mode, documents and images. Free usage varies. File format matters; paste short notes if the file is rejected.
  • Gemini: mobile input shortcuts, Gemini Live, uploads, free-plan limits. Uploading requires sign-in; Live requires the mobile app.
  • Meta AI: official features and free-access FAQ. Meta lists text, voice, photos and documents, but does not give a complete free-plan/device matrix here. Verify the controls in your app; the table does not promise every feature in every Meta app.
