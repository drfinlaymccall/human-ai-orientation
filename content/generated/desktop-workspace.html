Copy, switch, paste, and come back

Copying puts selected text on your device’s clipboard, ready to paste elsewhere. It leaves the original text in place. Copying something else usually replaces what is ready to paste.

  1. Select: drag across the text you want. In one of the course’s text boxes, click inside it and use Select All if you want the whole box. Many AI apps also have a Copy button below each reply.
  2. Copy: use the Copy command or the shortcut for your device below.
  3. Switch: click your AI’s browser tab or switch to its app. Keep this course tab open so you can return.
  4. Paste: click or tap inside the AI’s message box first, then paste. Read what appeared before you press Send.
  5. Come back: copy the AI’s answer, switch to this course tab, click inside the response box and paste. Only bring back text you want to keep here.
Mac shortcuts

Inside a text box: Command+A selects all, Command+C copies, and Command+V pastes. Hold Command and press Tab to switch apps. For two tabs in one browser, click the tab you want. You can also use the app’s Edit menu for Copy and Paste.

Windows shortcuts

Inside a text box: Ctrl+A selects all, Ctrl+C copies, and Ctrl+V pastes. Hold Alt and press Tab to switch apps. For two tabs in one browser, click the tab you want. You can also right-click selected text and choose Copy, then right-click the destination text box and choose Paste.

Phone or tablet

Use the course’s Copy button, or touch and hold text and adjust the selection handles, then tap Copy. Switch using your device’s app switcher or browser tab list. Touch and hold inside the destination text box and tap Paste. Menu wording varies by device and app.

The wrong text appeared, or nothing happened

Check that you selected the intended text and clicked inside the destination box. Copy the original again, then paste. If you replace something by mistake, use Undo (Command+Z on Mac or Ctrl+Z on Windows). The course also selects the text for manual copying if automatic copying is blocked.

Find the controls before you send anything

Open your chosen AI in another tab or app, keeping this course open. Find the message box, Send button, New chat button and chat history. Look for an attachment control (often + or a paperclip), a microphone, and a voice-conversation control (often a sound wave). Read their labels: icons vary. A missing button may mean that feature is unavailable in your app.

Two ways to speak: dictation turns speech into text, which you can check and edit before sending where the app allows. A live voice conversation listens and answers aloud, often responding when you pause. Learn how to stop or mute it. Voice is not always just transcription, and a transcript can mishear you. You can always type instead.

Give one useful instruction, then refine it

Choose something small: draft a message you need, make a short checklist, or explain something you want to understand. Say what you want done, add a relevant detail, and say what would make the answer useful. Start with a way of communicating that suits you; then explore a second input type if available. Type or paste an instruction
  1. Start a new chat. Type a small request in the message box, or copy the example below.
  2. Read it before sending. Check the answer against what you asked for.
  3. Give a follow-up: “Make it shorter and keep the date and venue as placeholders.” Did it follow both instructions?
Speak an instruction
  1. Try the app’s dictation control, if available. Allow microphone access when you choose to use it.
  2. Say the example below or your own request. Check any transcribed text, especially names, numbers and “do not”, before sending if possible.
  3. Ask for one change using your voice. If you use live conversation instead, listen for the change and practise ending or muting the session. Review the text afterward if available.

No microphone, quiet space or voice feature? Type the same instruction. You can explore speaking another time.

Give an instruction with a file
  1. Use the fictional practice note you found earlier. Open and read it first.
  2. Use the AI’s attachment control. Select the intended file and check its name. If Markdown (.md) is rejected, paste the note’s text into the message instead.
  3. Add the instruction below and send. Compare its answer with the note: did it use the known facts and leave the unknowns open? Attaching a file alone does not explain what you want done.
Give an instruction with a picture
  1. Write three lines on paper: “Community gathering”, “For neighbours”, “Date and venue undecided”. Take a clear photo showing only the paper, or use a screenshot of those fictional lines.
  2. Attach the picture with the AI’s image/attachment control. Check the thumbnail and add the instruction below. A still photo is enough; no live camera session is needed.
  3. Compare the answer with the visible words. Correct any misread or invented detail. Try: “The venue is undecided. Please remove the invented venue and use [venue].”

If image input is unavailable, type the three lines and ask the same question. That practises giving an instruction, although it does not test image reading.

Check what happened

Ask yourself: What did I tell it to do? Which detail did it use or miss? Did my follow-up change the answer in the way I wanted? Keep one useful response and one observation in your notes. Trying two input types helps you choose what suits a task; a different result does not prove that one input type is better.

Just exploring? Walk through an example

For the fictional gathering, imagine the AI replies: “Join us Saturday at Riverside Hall!” It has invented both details. A useful follow-up is: “The date and venue are undecided. Replace them with [date] and [venue].” A suitable revision might read: “Neighbours, join us for a community gathering on [date] at [venue].” Label this as example exploration in your notes; you can try it with your own AI later.

Say it first, then check it

Click in the box and use your device’s dictation to speak your answer instead of typing. Stop, read the words and correct anything it misheard. Keep only what you mean.

How to start voice typing

Windows 11: click in the box, then press Windows key + H. Select the microphone to stop. It needs a microphone and internet access. Windows setup guide (opens a new tab).

Mac: turn on Dictation in System Settings → Keyboard. Click in the box, then use the shortcut shown there or Edit → Start Dictation. Press Escape to stop. Mac setup guide (opens a new tab).

Phone or tablet: if your keyboard offers a microphone, use it to dictate into the selected box. You can also speak a draft in your usual AI app, review it there, then paste the parts you choose here. Typing, pasting and fictional examples work too.

These writing boxes do not record your microphone. Dictation uses your chosen device or app; check its settings if you are unsure what it sends or keeps.
